# EcoTrackAI

AI-Powered Campus & City Waste Segregation and E-Waste Tracker.

## Features

- AI-based waste classification
- Smart bin monitoring using ultrasonic sensor
- E-waste lifecycle tracking using QR codes
- Collection alerts for full bins
- Green Credits for responsible waste disposal

## Technology

- Python
- FastAPI
- MySQL
- PyTorch
- ResNet18
- HTML, CSS, JavaScript
- Arduino
- Ultrasonic Sensor
- QR Code
